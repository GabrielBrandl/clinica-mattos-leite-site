# Clínica Mundi

Site institucional da Clínica Mundi (Manaus/AM) — Cardiologia e Pediatria.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Deploy: Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

## Conformidade incluída

- Política de Privacidade, Termos, Cookies, Reembolso
- Banner de cookies com opt-in de analytics (LGPD)
- Formulário com consentimento e coleta mínima
- Acessibilidade (skip link, foco, alt, contraste, teclado)
- Dados empresariais (CNPJ, endereço, contatos)
- Sem avaliações fabricadas nem promessas de resultado
